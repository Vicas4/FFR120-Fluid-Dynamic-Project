# FFR120 Victor Valjus Fluid Dynamics Project

## Abstract
In this project i want to simulate the fluid dynamics of large waves crashing on a beach and how different methods can be used to prevent large waves to cause flooding. Perhaps placing walls along beach, and how different shapes of the walls can redirect the waves in different ways.

## Methods
I will use a particle based fluid simulation, mainly following the paper given in the project topic slide. 

## References
